# 5. Licensing: MIT for code, CC0 for tune data

Status: Accepted

## Context

Code and tune data have different audiences. Tune data should be reusable anywhere without
friction, and folk tune copyright is easy to get wrong.

## Decision

- Code is licensed under MIT (root `LICENSE`).
- Tune data in `tunes/` is dedicated to the public domain under CC0 1.0 (`tunes/LICENSE`).
- Contributors may only add their own transcriptions or material in the public domain in both its
  country of origin and their own country, never copies from copyrighted editions, and must
  record the source.
- License files are managed by the maintainer only.

## Consequences

- Anyone can reuse the tune collection without attribution requirements.
- Every tune contribution needs a source and a data-rule confirmation, which reviewers check.
