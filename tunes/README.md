# Tunes

This folder holds the tune data: folk tunes in [ABC notation](https://abcnotation.com/). Everything
here is dedicated to the public domain under [CC0 1.0](LICENSE), separately from the MIT-licensed
code.

## Format

- **One tune per file**, with the `.abc` extension.
- Use a short, lowercase, hyphenated file name based on the main title, for example
  `the-silver-spear.abc`.
- Include at least the `X:`, `T:`, `M:`, `K:` fields, and record the source in `S:` (and notes in
  `N:` if helpful). Alternative titles go in extra `T:` lines, the tradition or region in `O:` or
  `R:`.

## Data contribution rule

- Only contribute transcriptions you made yourself, or material in the public domain both in its
  country of origin and in your own country.
- Never copy from published tune books or other copyrighted editions.
- Always record the source.
